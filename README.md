# AI 答题助手 (QSanswer)

> 一个运行在本地的 AI 网页答题陪练工具：截图秒解 + 错题沉淀 + 知识图谱一站式闭环。

通过悬浮窗截图或自动检测题目，调用 DeepSeek V4 Pro 多模态模型直接解题；做错的题一键入册错题本，AI 三段式诊断错因并提取知识点，最终汇聚为可交互的 D3.js 力导向知识图谱，帮助学习者精准定位薄弱环节。

支持 Firefox / Edge，安装 Tampermonkey 脚本后，在任何网页上都能使用。

## 版本演进

本项目历经多次迭代，从「单点答题工具」演进为「学情闭环陪练」。

### v1.0 · 截图答题基线版

> 提供最核心的「截图 → 识别 → 解答」能力。

- 📸 **截图答题**：Win+Shift+S 截图题目，Ctrl+V 粘贴到面板，AI 视觉识别解题
- 🔍 **自动检测**：抓取网页文本，自动找出题目并解答
- 💬 **连续追问**：答题后可继续追问，保持上下文
- 🧠 **三种推理模式**：普通 / 深度思考 / 极限推理
- 📋 **历史记录**：所有问答自动保存到本地文件
- 🎨 **蓝白主题**：悬浮窗，可拖拽，全屏模式下也能用

### v2.0 · 错题沉淀版

> 在答题基础上加入错题管理，让做错的题不再丢失。

- 📒 **错题一键入册**：答题后点「做错了」自动加入错题本
- 🧪 **AI 三段式错题分析**：错因诊断 → 知识点标签 → 同知识点变式练习题
- ✏️ **交互式练习**：基于变式题即时练习，对错反馈
- 🗂️ **错题本基础管理**：列表查看、按学科/知识点筛选、分页
- 📊 **雷达图视图**：知识点掌握度可视化（初版）

### v3.0 · 闭环增强版（当前版本）

> 面向「学情可视化 + 高效管理」全面升级，形成完整学习闭环。

- 🕸️ **D3.js 力导向知识图谱**：替代传统雷达图，节点大小映射错题数、颜色映射学科、边表示知识点共现；支持缩放 / 拖拽 / 单击筛选 / 双击高亮关联节点
- ➕ **多错题累计标记**：一次答题可连续加入多道错题，实时计数提示
- 🔧 **错题本 CRUD 全功能**：增删改查、批量分析、合并去重、批量删除
- 📤 **多格式导出**：用户可选 JSON / CSV / Markdown 三种格式，支持导出选中或全部
- 🎯 **三通道截图上传**：粘贴（局部+全局）+ 拖拽 + 文件选择，修复粘贴失效 bug
- ⚡ **批量分析进度条**：批量 AI 分析实时反馈进度，避免等待焦虑
- 🎨 **统一视觉系统**：靛蓝强调色 + 中性暖灰底色 + 学科颜色映射

## 快速开始

### 1. 获取 API Key
注册 [DeepSeek](https://platform.deepseek.com/api_keys) 并创建 API Key。

### 2. 配置
在项目目录创建 `.env` 文件：
```
DEEPSEEK_API_KEY=sk-你的APIKey
```

### 3. 启动服务
双击 `start.bat`（Windows）或运行：
```bash
pip install -r requirements.txt
python server.py
```

### 4. 体验入口（三选一）

**入口 A · 网页版面板**（无需安装油猴脚本）
- 浏览器访问 `http://127.0.0.1:5000/panel`

**入口 B · 油猴悬浮球**（任意网页可用）
1. 安装 [Tampermonkey](https://www.tampermonkey.net/) 扩展
2. 新建脚本，粘贴 `tampermonkey_script.js` 全部内容
3. 打开任意网页，右下角出现蓝色悬浮球

**入口 C · 错题本与知识图谱**
- 浏览器访问 `http://127.0.0.1:5000/analysis`
- 或在悬浮窗答题后点「做错了」自动引导

### 5. 演示页面
仓库自带两个演示页，方便快速体验：
- `http://127.0.0.1:5000/exam` — 计算机基础测试
- `http://127.0.0.1:5000/bio` — 高中生物模考

## 核心功能详解

### 📸 截图答题（三通道上传）

支持三种截图输入方式，任意场景都顺畅：
- **粘贴**：Win+Shift+S 截图后 Ctrl+V 粘贴（兼容全局与面板内粘贴）
- **拖拽**：将图片文件直接拖到截图区
- **文件选择**：点击「📂 选择图片文件」按钮

### 🧠 AI 三段式错题分析

点击「分析错题」后，DeepSeek V4 Pro 给出：
1. **错因诊断** — 详细分析为什么做错
2. **知识点标签** — 自动提取相关知识点
3. **变式巩固题** — 同知识点新题目供练习

### 🕸️ D3.js 力导向知识图谱

错题本的全部知识点自动构建为可交互网络图：
- 节点大小 = 该知识点错题数
- 节点颜色 = 学科分类
- 节点连线 = 知识点共现关系
- 交互：缩放 / 拖拽节点 / 单击筛选 / 双击高亮关联 / Tooltip 详情

### 📒 错题本全功能管理

- **CRUD**：新增、查看、编辑、删除
- **批量操作**：多选 + 批量分析 / 批量删除
- **合并去重**：将重复或相关错题合并为一条（question 用 `———` 分隔拼接，知识点取并集）
- **多格式导出**：JSON / CSV / Markdown 三种格式任选，支持导出选中或全部

## 技术栈

- **后端**：Python 3.12 + Flask（13 个 API 路由）
- **AI 模型**：DeepSeek V4 Pro API（视觉识别 + 文本推理 + 错题分析）
- **数据存储**：MySQL（错题本持久化）
- **浏览器端**：Tampermonkey + Shadow DOM（悬浮窗隔离）
- **可视化**：D3.js v7.8.5 力导向图
- **前端**：原生 JavaScript + HTML5（无框架依赖，启动零门槛）

## API 接口

### 答题相关
| 方法 | 路径 | 说明 |
|---|---|---|
| POST | `/api/vision` | 截图视觉识别答题 |
| POST | `/api/ask` | 文本提问 |
| POST | `/api/chat` | 连续追问 |

### 错题本管理
| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/wrong/notebook` | 错题列表（分页） |
| GET | `/api/wrong/notebook/<id>` | 错题详情 |
| PUT | `/api/wrong/notebook/<id>` | 编辑错题 |
| DELETE | `/api/wrong/notebook/<id>` | 删除错题 |
| POST | `/api/wrong/quick-add` | 快速入册（不调 AI） |
| POST | `/api/wrong/notebook/merge` | 合并多条错题 |
| POST | `/api/wrong/notebook/batch-delete` | 批量删除 |
| GET | `/api/wrong/notebook/export` | 导出（json/csv/md） |
| POST | `/api/wrong/batch-analyze` | 批量 AI 分析 |

### 分析与可视化
| 方法 | 路径 | 说明 |
|---|---|---|
| POST | `/api/wrong/analyze` | 单条错题 AI 分析 |
| POST | `/api/wrong/practice` | 变式练习 |
| GET | `/api/wrong/stats` | 学科/知识点统计 |
| GET | `/api/wrong/graph` | 知识图谱数据 |
